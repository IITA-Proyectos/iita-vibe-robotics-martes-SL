El código está organizado por plataforma:

* [lego-ev3-pybricks](file:///c:/Users/ativa/OneDrive/Documentos/IITA/VC/iita-vibe-robotics-martes-SL/codigo-clases/lego-ev3-pybricks): Códigos y reportes de clase para LEGO MINDSTORMS EV3 utilizando Pybricks.
