# Códigos de Clase

Este directorio contiene los programas, rutinas de calibración y reportes de clase desarrollados por los alumnos y docentes en el taller de robótica de Vibe Robotics (IITA).

El código está organizado por plataforma:
* [arquero-teensy-zircon](arquero-teensy-zircon/): Robot **arquero** de fútbol (Roboliga 2026) — Teensy 4.1 sobre placa Zircon, cámara OpenMV y giroscopio BNO055. Bitácoras de clase, pruebas de banco y programas que funcionan.
* [delantero-teensy-zircon](delantero-teensy-zircon/): Robot **delantero** de fútbol (Roboliga 2026) — Teensy 4.1 sobre placa Zircon, cámara OpenMV. Busca la pelota, la orbita y patea al arco. Bitácoras, pruebas de banco, calibración de la cámara y mejoras pendientes.
* [lego-spike-pybricks](file:///c:/Users/ativa/OneDrive/Documentos/IITA/VC/iita-vibe-robotics-martes-SL/codigo-clases/lego-spike-pybricks): Códigos para hubs LEGO Spike Prime utilizando MicroPython de Pybricks.
* [lego-ev3-pybricks](file:///c:/Users/ativa/OneDrive/Documentos/IITA/VC/iita-vibe-robotics-martes-SL/codigo-clases/lego-ev3-pybricks): Códigos y reportes de clase para LEGO MINDSTORMS EV3 utilizando Pybricks.
