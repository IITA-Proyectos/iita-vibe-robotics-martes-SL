# Pruebas de banco

Programas cortos para **medir y diagnosticar**, no para jugar. Cada uno responde una pregunta
concreta y después para.

No usan `zirconLib` ni el giroscopio a propósito: así compilan y corren siempre, sin depender
de los dos problemas P0 que hoy tiene el código de competencia
(ver [`../bugs-conocidos.md`](../bugs-conocidos.md)).

| Prueba | Responde |
|---|---|
| [`identificar-robot/`](identificar-robot/) | ¿Este robot es el arquero o el delantero? |

## Regla de oro

**Nada de esto está validado.** Son programas propuestos: quien dice si funcionan es el que
tiene el robot en la mano. Anoten el resultado en [`../bitacora/`](../bitacora/) — con los
números, no con "anduvo".
